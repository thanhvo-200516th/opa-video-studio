# Xoá metadata ảnh & clip trước khi giao

Người dùng muốn mọi ảnh/clip giao cho họ không còn thông tin cho biết ai hoặc công cụ nào tạo ra: `Software`, `Artist`, `CreatorTool`, C2PA "Generated by…", IPTC `DigitalSourceType = trainedAlgorithmicMedia`, prompt Stable Diffusion/ComfyUI, comment, GPS. Kết quả tương đương đưa file qua exiftools.com, nhưng xử lý cục bộ để file không rời máy.

Nếu người dùng yêu cầu giữ metadata cho một file cụ thể (ảnh gốc cần EXIF máy ảnh, file cần giữ Content Credentials…), làm theo yêu cầu đó.

## Cách làm

Chạy ở bước cuối, sau mọi xử lý có thể ghi lại metadata (resize, nén, ghép, export) và trước khi gửi file hoặc đưa đường dẫn — kể cả khi gửi qua Feishu, WeChat, Drive:

```bash
python3 ~/.agents/skills/strip-media-metadata/scripts/strip_metadata.py <file>...
```

- Sửa tại chỗ (ghi file tạm cạnh file rồi thay thế). Không ghi đè file gốc người dùng đưa vào trừ khi họ yêu cầu làm sạch chính file đó; nếu cần giao lại bản gốc, strip một bản copy.
- `STRIPPED` / `CLEAN` = đạt. `LEFTOVER`, `ERROR`, `UNSUPPORTED` = chưa sạch (exit 1): xử lý tiếp hoặc báo người dùng, không giao như thể đã sạch.
- `--check` chỉ báo cáo metadata đang có, không sửa file.
- Cần `python3`; video cần thêm `ffmpeg` và `ffprobe`.

## Phạm vi

- **Ảnh JPEG, PNG, WebP, GIF (cả ảnh động):** lossless, pixel giữ nguyên byte. Giữ lại Orientation (để ảnh chụp không bị xoay sai), JFIF/Adobe APP14, thông số hiển thị PNG (gamma, sRGB, pHYs, APNG), vòng lặp GIF.
- **Video MP4/MOV/M4V, MKV/WebM, AVI:** ffmpeg `-c copy`, không encode lại; giữ video, audio, phụ đề; bỏ tags, chapters, data stream (timecode, GPS telemetry), box `uuid`/C2PA; MP4/MOV được đặt `faststart`.
- **ICC profile mặc định bị xoá** (giống `exiftool -all=`). Ảnh wide-gamut (Display P3 từ iPhone) có thể lệch màu nhẹ — dùng `--keep-icc` khi màu quan trọng.
- **HEIC/AVIF/TIFF và định dạng khác → `UNSUPPORTED`:** chuyển sang JPEG/PNG/WebP hoặc MP4 rồi strip, hoặc báo người dùng.

## Giới hạn — nói rõ với người dùng khi liên quan

- Chỉ xoá metadata. Watermark ẩn trong điểm ảnh (Google SynthID…) và watermark hiển thị vẫn còn; không khẳng định file "không thể bị nhận ra là AI".
- Tên file cũng có thể lộ nguồn (`ChatGPT Image …png`, `Gemini_Generated_…`): đặt tên trung tính cho file bạn tạo; không tự đổi tên file người dùng đã đặt.
- Video vẫn còn chuỗi encoder trong bitstream (vd. SEI `x264 - core 165`) và tên muxer `Lavf` trong MKV/WebM — đây là tên công cụ mã hoá, không phải người hay AI tạo nội dung.
